# Personal Portfolio Website

This is a personal portfolio website developed using **HTML**, **CSS**, and **JavaScript** to showcase my skills, academic background, projects, work experience, and contact details in a visually appealing and user-friendly format. It reflects both my technical capabilities and creative design sense.

## Live Demo

[View Portfolio Live](aadi81.github.io/My_Portfolio/) 


## About the Project

This portfolio website serves as a digital resume that highlights:

- My personal introduction
- Technical skills
- Completed projects with live previews and source code
- Resume download option
- Contact form to reach out directly via email
- Clean, responsive UI design suitable for all devices



## Features

- Fully responsive layout for mobile, tablet, and desktop
- Interactive and modern animations with JavaScript
- Smooth scroll navigation
- Sticky navigation bar
- Form validation using vanilla JavaScript
- SEO-optimized meta tags
- Fast load time with optimized assets



## Website Sections

### 1. **Home**
- Eye-catching banner or hero section
- Name, title (e.g., Full Stack Developer), and a short welcome message
- Animated typing or fade-in effects

### 2. **About Me**
- Personal introduction
- Education background
- A short summary of your career goals or interests

### 3. **Skills**
- List of technical skills (HTML, CSS, JavaScript, etc.)
- Tools and frameworks (VS Code, GitHub, Bootstrap, etc.)
- Progress bars or icons representing proficiency

### 4. **Projects**
- Showcase of selected projects
- Each project card includes:
  - Project title
  - Description
  - Technologies used
  - Live demo link
  - GitHub source code link

### 5. **Resume**
- Button to download resume (PDF)
- Embedded preview (optional)

### 6. **Contact**
- Contact form with name, email, and message fields
- EmailJS or formspree integration (optional)
- Social media icons linking to LinkedIn, GitHub, etc.

### 7. **Footer**
- Copyright
- Social media links
- Navigation shortcut
